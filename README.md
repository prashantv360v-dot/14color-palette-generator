
# 🎨 Color Palette Generator

A responsive color palette generator built using HTML, CSS, and JavaScript.

## Features

- Generate 7 random HEX colors.
- Click any color swatch to copy its HEX code.
- Generate unlimited random palettes.
- Responsive mobile, tablet, and desktop layout.
- Keyboard shortcut: press Space to generate a new palette.
- Copy confirmation notification.
- Accessible keyboard controls and hover effects.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Click a color to copy its HEX code.
4. Click Generate New Palette to create new colors.
